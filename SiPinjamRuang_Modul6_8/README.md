# Source Demonstrasi Modul 6 dan Modul 8

Folder ini mengelompokkan contoh OOP yang digunakan untuk proyek akhir SiPinjamRuang.

## Modul 6
- Pengguna.java: abstract class dengan atribut private, getter/setter, dan abstract method.
- Admin.java serta Mahasiswa.java: inheritance, super, overriding, dan implementasi interface.
- PeminjamanRuangan.java: data peminjaman dengan atribut private dan validasi input.
- IdentitasLogin.java dan MemilikiPeran.java: kontrak interface untuk akun.

## Modul 8
- com/praktikum8/Hewan.java, Kucing.java, Anjing.java: runtime polymorphism.
- BangunDatar.java dan Lingkaran.java: abstract class dan abstract method.
- AlatElektronik.java, Kamera.java, Smartphone.java: implementasi lebih dari satu interface.
- PoliTester.java: kelas demonstrasi untuk menjalankan semua contoh.

## Menjalankan
Tempatkan berkas di bawah Source Packages dengan struktur package yang sama. Klik kanan PoliTester.java dan pilih Run File. Jika model telah ditambahkan pada proyek web, lakukan Clean and Build.

Pengujian PoliTester berjalan di memori dan tidak mengubah database.
